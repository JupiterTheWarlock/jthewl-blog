我想起来我在半年多之前，是看不懂readme中的项目部署方式的：
类似

npm install
npm run dev

我就会想：在哪输命令行，为什么我输入了命令行后会报错？我是不是少做了啥...是不是要拉到~/，没有特殊说明的话是不是每次都拉到~/

这样子的尴尬新手期应该不止发生在我身上
