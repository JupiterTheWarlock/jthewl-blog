# AI coding是否正在剥夺程序员的coding能力

type: Post
status: Published
date: 2026/04/20
tags: AI, 编程, 思考
category: 随笔

我现在已经基本很少手写代码了，每一天工作期间手写的提示词数量绝对要远远超于手写的代码数量。

效率提高了吗？提高了很多，但可能也没有想象中的那么多，应该提高50~100%？在体量较大的项目中如果全力满状态爆肝手写代码的话，极限情况下应该是可以和ai coding的工作量持平。这点我也不是非常确定，因为没有具体量化过。

但我可以肯定的一点是ai coding比手写代码要省心无数倍，再也不需要对着代码焦头烂额了。

我有一些担忧我未来的coding能力会不会因此下降，我现在甚至都懒得自己去读代码了，通常是让ai帮我读。说好听点我叫AI natives，说难听点我这就是坐在AI轮椅上啊。

不过，我会认为我的担忧出于感性而非理性。

在我的理性认知中，我目前的状态正是进化的表现。程序员可以从繁杂的业务之中抽离，让AI帮忙处理下面的基层的内容，而人类更加专注于高层的抽象的工作，比如说系统架构等。

但话又说回来。我现在的基础真的足够支撑我专注于高层的抽象的工作吗？这可能就是我这个菜鸡的不安的来源。

可能陆地生物的祖先第一次从海里爬上陆地的时候，也会和我现在一样感到不安吧。
